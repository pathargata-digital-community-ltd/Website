# পাথরঘাটা ডিজিটাল ব্লগ

এই static GitHub Pages site-এ নতুন post যোগ করতে:

1. `blog/posts/`-এ নতুন `.html` ফাইল তৈরি করুন।
2. আলাদা `<title>`, meta description, canonical URL, Open Graph metadata এবং `Article` JSON-LD দিন।
3. মূল লেখায় একটি H1, পরিষ্কার H2 heading, author/published date, source এবং last updated date রাখুন।
4. `blog/index.html`-এ নতুন post card যোগ করুন।
5. Homepage-এর blog preview-এ শুধু নির্বাচিত গুরুত্বপূর্ণ post যোগ করুন।
6. `sitemap.xml`-এ নতুন URL ও lastmod যোগ করুন।
7. তথ্য প্রকাশের আগে স্থানীয়/সরকারি উৎস থেকে যাচাই করুন।

এটি একটি static publishing system; GitHub-এ commit/push করলেই GitHub Pages-এ প্রকাশ হবে।
